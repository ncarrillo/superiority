# Superiority 0.1.34

This release improves connection reliability and expands native protocol inspection.

## Reliability

- Fixed public-channel reconnect failures caused by variations in Battle.net join responses.
- Channel join and removal errors now use Battle.net’s human-readable error messages.
- Improved handling of fragmented native traffic and record boundaries.

## Protocol Analyzer

- Expanded decoding coverage across more Sunken services and message types.
- Added support for generated BSN wire layouts, including reordered fields and filler bits.
- Improved field-level inspection and handling of previously unknown native records.

## Interface

- Corrected vertical alignment between presence indicators and labels everywhere they appear.
