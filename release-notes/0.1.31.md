# Superiority 0.1.31

This Windows hotfix improves Protocol Viewer window behavior and taskbar
shortcuts.

## Windows

- Added native window controls to Protocol Viewer.
- Fixed taskbar jump-list actions opening a second Superiority instance.
- **Check for Updates** now activates the running app and opens the update
  modal.
- About, Settings, and Protocol Viewer shortcuts now also reuse the running
  app.
