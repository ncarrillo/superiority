# Superiority 0.1.28

This release replaces the withdrawn 0.1.27 update. It restores reliable update
checks and includes the channel and roster improvements intended for that
release.

## Reliability

- Fixed an HTTPS configuration error that prevented the new updater from
  reaching the update service.
- Added a live update-service check to the release process so the updater's
  network path is verified before publication.
- Improved updates for applications installed in locations that require
  administrator approval.

## Channels

- Added the current public channel catalogue and human-readable channel names.
- Public channels can now be joined by name as well as by identifier.
- Existing **General** channel preferences migrate to the current channel
  automatically.
- Improved public channel join matching when Battle.net omits or changes request
  metadata.
- Added channel type, shard, and identity details to roster headers.

## Rosters

- Clanmates and party members are grouped and highlighted consistently in the
  desktop app and Superiority Live.
- Away members are easier to distinguish.
- Member ordering remains stable as presence and roster updates arrive.
- Roster searches are now kept separately for each channel.
- Improved identity consistency between the desktop app and Superiority Live.
