# Superiority 0.1.33

This release expands protocol inspection and polishes scrolling and controls
throughout the application.

## Protocol Analyzer

- Added visualization for HTTP requests and responses.
- Added detailed BGS message inspection, including RPC headers and protobuf
  fields.
- Added request and response correlation and visibility into malformed BGS
  messages.
- Sensitive HTTP headers are automatically redacted.
- Fixed Protocol Analyzer window dragging on Windows.

## Interface

- Added native-style scrollbars throughout user, social, join, transcript, and
  other scrollable lists.
- Fixed malformed scrollbars in Social and Join lists.
- Fixed the transcript scrollbar.
- Improved focus outlines for consistency with the Protocol Analyzer.
- Corrected checkbox label alignment.
- Fixed the notification indicator appearing behind its button.
