# Superiority 0.1.25

This release adds an in-app Protocol Viewer for exploring live StarCraft II
traffic.

## Protocol Viewer

- Capture and inspect protocol records as they arrive.
- Browse decoded payloads alongside their original bitstream, byte, and ASCII
  representations.
- Select decoded fields to highlight the corresponding source data.
- Filter records and decoded properties by typing.
- Navigate lists with the keyboard.
- Pause, resume, or clear a capture at any time.
- Added field descriptions and contextual tooltips throughout the inspector.

## Improvements

- Expanded decoding coverage for complex messages.
- Improved the accuracy of field-to-bit-range tracking.
- Improved inspector readability, selection clarity, panel resizing, scrolling,
  and keyboard focus.
- Added clearer visual grouping for different protocol services and commands.
- Fixed several decoded values appearing without their source ranges.
