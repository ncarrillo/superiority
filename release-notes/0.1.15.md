# Superiority 0.1.15

This release makes updates and modal transitions feel like one coherent part of the application.

## Updates before connection

- Superiority now checks for updates before starting the automatic Battle.net connection.
- An available update is presented before authentication begins.
- If the installed version is current—or the update service cannot be reached—the connection continues automatically.

## Consistent modal transitions

- Every in-app modal now has a coordinated opening and dismissal animation.
- Friends, connection, error, and software-update dialogs use the same scan-and-glow transition language as Settings.
- Modal content is reset after its closing animation completes, preventing abrupt disappearances.

## Unified headers

- Blue modal headers now share the same title renderer, typography, and glow treatment.
- Warning dialogs preserve their distinct orange error presentation.
