# Superiority 0.1.30

This release introduces the public Windows build and brings its desktop
experience in line with macOS.

## Windows

- Added a signed 64-bit Windows download with signed in-app updates.
- Added native minimize, maximize, restore, and close controls.
- The application window can now be moved using the title bar.
- Moved the user tile and account menu to the left to make room for Windows
  window controls.
- Added About, Check for Updates, Settings, and Protocol Viewer to the taskbar
  jump list.
- Removed the macOS-only tab offset from the Windows layout.

## Reliability

- Fixed Windows HTTPS trust handling for Battle.net login, public channels, and
  software updates.
- Improved release versioning and update metadata for cross-compiled Windows
  builds.
