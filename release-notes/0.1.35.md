# Superiority 0.1.35

Superiority now brings StarCraft II, StarCraft: Remastered, and Warcraft III together in one Battle.net client.

## Three games, one account

- Added a game picker for StarCraft II, StarCraft: Remastered, and Warcraft III.
- Superiority detects which games belong to the signed-in Battle.net account and only offers available titles.
- Each game shows its connection state, region, current channel, online population, and errors.
- Games remain connected in the background, so returning to the game picker or entering another game does not disconnect the current one.
- Added account-wide refresh and sign-out controls.
- Added mouse and keyboard navigation for choosing and entering games.

## StarCraft: Remastered

- Added initial support for the U.S. East gateway.
- Join public channels or named custom channels.
- Send messages, emotes, whispers, and supported classic Battle.net commands.
- Added `/help` for commands advertised by Battle.net.
- Added friends, private conversations, live channel rosters, operator status, join and leave activity, and classic character avatars.
- Introduced a dedicated Terran-console interface inspired by classic Battle.net.

## Warcraft III

- Added Warcraft III chat support.
- Discover and join public channels, keep several channels open, reorder their tabs, and leave them individually.
- Added channel rosters with Warcraft portraits, presence, and clan tags.
- Added friends and private conversations.
- Added the Clan Hall with the clan name, tag, description, message of the day, member count, ranks, and roster.
- Added Warcraft-themed typography, controls, and Human, Night Elf, Orc, and Undead backgrounds.

## StarCraft II

- Added a party strip showing party members, presence, leader, and available seats.
- Added inline party chat. Use `/p` to switch the composer to party chat or `/p message` to send one party message without leaving the current channel.
- Fixed connections failing for accounts that have blocked StarCraft II players.
- Improved handling of whispers, friend invitations, party presence, lobby presence, and profile data.

## Interface

- StarCraft II, StarCraft: Remastered, and Warcraft III now have their own visual identity throughout chat, rosters, inputs, dialogs, settings, and navigation.
- Background choices are saved separately for each game.
- Transcript selection and copying are supported across the new game interfaces.
- Background game activity no longer interrupts the message being typed in the foreground.

## Superiority Live

- A single Live link can carry StarCraft II, StarCraft: Remastered, and Warcraft III activity.
- Live viewers receive a game picker when more than one game is being shared.
- Each game is presented with its matching interface, avatars, portraits, channels, and roster.
- Live transcripts now preserve emotes, server notices, and member join and leave activity.
- Existing StarCraft II Live feeds remain compatible.

## Website

- Rebuilt the Superiority landing page around the new multi-game experience.
- Added current release notes, direct downloads for macOS and Windows, and a dedicated link to SC2Docs.

## Reliability

- Connections now fail with an actionable error instead of remaining stuck indefinitely.
- Product sessions stay on the same Battle.net account when cached credentials need to be refreshed.
- Game availability is based on the account's Battle.net licenses and game profiles.
- Refreshing or switching games preserves the active account and reconnects only what is needed.
